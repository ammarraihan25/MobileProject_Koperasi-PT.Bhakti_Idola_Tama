# MobileProject_Koperasi-PT.Bhakti_Idola_Tama

Aplikasi Mobile Moobi Koperasi PT. Bakti Idola Tama dibangun menggunakan React Native / Expo & TypeScript.

## 📱 Fitur Utama
- **Autentikasi**: Login & Registrasi Anggota
- **Dashboard / Home**: Ringkasan saldo, pinjaman, dan menu cepat
- **Simpanan**: Informasi saldo pokok, wajib, sukarela, serta mutasi
- **Pinjaman**: Pengajuan pinjaman, kalkulator simulasi, dan status cicilan
- **Kantin Moobi / Belanja**: Katalog produk & pemesanan
- **Transfer & Tagihan**: Transfer antar anggota, virtual account, dan pembayaran tagihan
- **Profil & Pengaturan**: Data anggota, keamanan PIN/Biometrik, riwayat transaksi

## 🚀 Memulai (Getting Started)

1. Masuk ke direktori aplikasi mobile:
   ```bash
   cd moobi-koperasi-mobile
   ```

2. Instal dependensi:
   ```bash
   npm install
   ```

3. Jalankan server pengembangan Expo:
   ```bash
   npm run dev
   # atau
   npx expo start
   ```

4. Buka di Expo Go (Android / iOS) atau di Web browser.
